# 📋 دليل تذكيرات الفوترة في GitHub — خطوة بخطوة

> **للتنفيذ الهادئ:** لا تحاول فعل كل شيء دفعةً واحدة.  
> افعل **خطوة واحدة فقط**، ثم ارتح، ثم انتقل للتالية.

---

## 1. ماذا تعني رسائل التذكير؟

| نوع الرسالة | ماذا يعني؟ |
|---|---|
| **Trial ending soon** | فترة التجربة المجانية توشك على الانتهاء |
| **Payment method required** | GitHub يحتاج وسيلة دفع قبل انتهاء التجربة |
| **Invoice pending / past due** | فاتورة مستحقة الدفع لم تُسدَّد بعد |
| **Action required on your plan** | يوجد إجراء مطلوب منك لاستمرار الخدمة |

**الخلاصة:** هذه مجرد تذكيرات آلية — لا يعني استمرارها أن هناك مشكلة كبيرة، بل أن هناك خطوة صغيرة مطلوبة.

---

## 2. تحقق من حالة خطتك أولاً (قبل أي إجراء)

**خطوة واحدة فقط الآن:**

1. اذهب إلى: **GitHub → Settings → Billing and plans**
   - لمنظمة: **Organization Settings → Billing and plans**
   - لـ Enterprise: **Enterprise Settings → Billing**
2. لاحظ:
   - [ ] ما هو اسم خطتك الحالية؟ (Free / Pro / Team / Enterprise)
   - [ ] هل هناك تاريخ انتهاء أو تاريخ استحقاق فاتورة؟
   - [ ] هل وسيلة الدفع مضافة أم لا؟

---

## 3. الإجراءات الآمنة — حسب حالتك

### أ) إذا لم تكن مستعداً للدفع الآن

- [ ] اذهب إلى صفحة Billing → ابحث عن **Cancel trial** أو **Downgrade plan**
- [ ] الرجوع إلى الخطة المجانية (Free) يوقف التذكيرات فوراً
- [ ] لا يُفقَد حسابك ولا مستودعاتك عند الرجوع للخطة المجانية

---

### ب) إذا كنت مستعداً لإضافة وسيلة دفع

- [ ] اذهب إلى: **Billing → Payment information → Add payment method**
- [ ] أدخل بيانات البطاقة أو حساب PayPal الصحيحة
- [ ] تأكد أن **عنوان الفوترة (Billing address)** مطابق لما هو مسجّل لدى البنك أو جهة الدفع
- [ ] احفظ التغييرات

---

### ج) إذا كنت بانتظار إثبات عنوان (Proof of Address)

> ⚠️ **مهم جداً:** لا تُدخل عنواناً غير صحيح أو وهمياً في خانة عنوان الفوترة.  
> البيانات المالية والقانونية يجب أن تكون دقيقة.

**بدائل آمنة أثناء الانتظار:**

- [ ] **الخيار 1 (الأفضل):** أوقف الإعداد مؤقتاً — لا تُكمل تعبئة بيانات الدفع حتى يصلك الإثبات الرسمي
- [ ] **الخيار 2:** استخدم عنوان صحيح ومُخوَّلاً لك استخدامه الآن (مثل عنوان الشركة أو جهة العمل، إن أذنوا لك)
- [ ] **الخيار 3:** تواصل مع دعم GitHub واشرح أنك بانتظار إثبات عنوان — فريقهم يفهم هذه الحالات

**ماذا تتجنب:**
- ❌ لا تكتب عنوان بلد غير صحيح في خانة Country
- ❌ لا تختلق عناوين لا تملك إثباتاً عليها
- ❌ لا تخلط بين عدة مدن/دول في خانة واحدة

---

### د) إذا أردت التواصل مع دعم GitHub

- [ ] اذهب إلى: [https://support.github.com](https://support.github.com)
- [ ] اختر الموضوع: **Billing** أو **Account**
- [ ] اشرح وضعك بإيجاز (بالعربي أو الإنجليزي — كلاهما مقبول)
- [ ] احتفظ برقم التذكرة (ticket number) للمتابعة

---

## 4. خطوات "تخفيف الحِمل الذهني"

> لو كل هذا يبدو كثيراً، ابدأ بهذه الخطوة الواحدة فقط:

**الخطوة الوحيدة الآن:**  
→ اذهب إلى صفحة Billing وانظر **هل هناك تاريخ محدد مذكور؟**

إذا نعم: دوّنه في مكان ما، وعُد لاحقاً لبقية الخطوات.  
إذا لا: يعني عندك وقت — لا حاجة للتسرع.

---

**تذكير أخير:**  
تذكيرات GitHub لا تعني أن شيئاً "كُسر" أو أنك نسيت — هي فقط نظام آلي يُنبّه.  
أنت في السيطرة، وكل خطوة صغيرة تُحسب. 🌱
