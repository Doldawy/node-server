# إرشادات العنوان وإثبات الإقامة (Proof of Address)

> **تحذير مهم:** إدخال عنوان مزيّف أو غير صحيح في أي نموذج رسمي (فوترة، Enterprise، منظمة) **مخالفٌ لشروط الخدمة** وقد يُفضي إلى عواقب قانونية ومالية. لا تُدخل بيانات كاذبة تحت أي ظرف.

---

## ⚠️ مخاطر استخدام عنوان مزيّف

| المخاطرة | التفاصيل |
|----------|----------|
| **إيقاف الحساب** | GitHub وكثير من المنصات تحتفظ بحق تعليق أو حذف الحساب عند اكتشاف بيانات غير صحيحة |
| **رفض الدفع** | بيانات الفوترة الخاطئة تُسبب فشل المعاملات البنكية |
| **مشاكل قانونية** | العنوان المزيّف في العقود والفواتير قد يُعدّ غشًّا تجاريًّا |
| **فقدان البيانات** | عند تعليق الحساب قد تُفقد الوصول إلى مستودعاتك ومشاريعك |
| **مشاكل ضريبية** | عنوان الفوترة يُستخدم لحساب الضرائب؛ أي خطأ يُسبّب فروقات ضريبية |

## ✅ البدائل الآمنة أثناء انتظار Proof of Address

### 1. أوقف الإعداد مؤقتًا
إذا لم يكن لديك عنوان رسمي حاليًّا، **أوقف عملية الإعداد** ولا تُكمل حتى تحصل على العنوان الصحيح. معظم المنصات تحفظ تقدّمك.

### 2. استخدم عنوانًا مؤقتًا مُصرَّحًا به
يمكنك استخدام أحد هذه العناوين كعنوان مؤقت **شريطة أن تكون مُخوَّلًا باستخدامه**:
- عنوان الشركة أو جهة العمل
- عنوان الإقامة الدائمة (الأسرة)
- عنوان بطاقة الدفع أو الحساب البنكي
- عنوان مكتب البريد (PO Box) المسجّل باسمك

### 3. استخدم النسخة التجريبية بدون فوترة
- بعض الخطط تتيح **تجربة مجانية** لا تتطلب عنوانًا فوريًا.
- ابدأ بالخطة المجانية ثم أضف بيانات الفوترة لاحقًا بعد توفّر العنوان.

### 4. تواصل مع دعم GitHub
- زُر [github.com/contact](https://github.com/contact) أو [support.github.com](https://support.github.com).
- اشرح وضعك بصدق: "أنا في انتظار وثيقة إثبات العنوان من صاحب العمل".
- يمكنهم تمديد مهلة التحقق أو اقتراح بدائل رسمية.

### 5. اختر الدولة الصحيحة وأترك الحقول الاختيارية فارغة
- **حقل الدولة (Country)** إلزامي في الغالب — اختر دولتك الحقيقية التي تمتلك فيها وثيقة رسمية.
- حقول المدينة/المنطقة/الرمز البريدي قد تكون اختيارية — اتركها **فارغة** إن لم تكن لديك بيانات دقيقة، بدلًا من ملئها بمعلومات خاطئة.

## 📋 قائمة المراجعة: انتظار Proof of Address

اتبع هذه الخطوات بالترتيب:

- [ ] **أوقف الإعداد** ولا تُدخل أي عنوان حتى تتوفر البيانات الصحيحة
- [ ] **تواصل مع الجهة المسؤولة** (الرؤساء / الموارد البشرية / الإدارة) وطلب إرسال وثيقة إثبات العنوان رسميًّا
- [ ] **حدّد موعدًا توقّعيًّا** لوصول الوثيقة واحتفظ بتذكير
- [ ] **تحقق من نوع الوثيقة المقبولة** (فاتورة خدمات، عقد إيجار، كشف بنكي، إلخ)
- [ ] بعد استلام الوثيقة: **أدخل العنوان الصحيح** في إعدادات الفوترة أو المنظمة
- [ ] **احتفظ بنسخة من الوثيقة** في مكان آمن خاص بك (ليس داخل المستودع)
- [ ] **تحقق من صحة البيانات** بعد الحفظ وتأكّد من نجاح أي معاملة دفع

## 🔄 كيفية تحديث العنوان لاحقًا

### في إعدادات الفوترة على GitHub
1. اذهب إلى **Settings → Billing and plans → Payment information**
2. انقر **Edit** بجانب عنوان الفوترة
3. أدخل العنوان الصحيح وانقر **Save**

### في إعدادات المنظمة (Organization)
1. اذهب إلى **Organization Settings → Billing**
2. حدّث بيانات الفوترة بالعنوان الصحيح

### في إعدادات Enterprise
1. اذهب إلى **Enterprise Settings → Billing**
2. حدّث بيانات الفوترة بالعنوان الصحيح

## 🔒 إرشادات الخصوصية — ما يجب حمايته

> **لا تُشارك ولا تُرفع هذه الوثائق داخل أي مستودع (Repository) أو قناة عامة:**

| ما يجب حمايته | السبب |
|---------------|-------|
| صور وثائق إثبات العنوان | تحتوي على بيانات شخصية حساسة |
| أرقام الهوية الوطنية | خطر سرقة الهوية |
| بيانات بطاقات الدفع | خطر الاحتيال المالي |
| عناوين البريد الإلكتروني الشخصية | قد تُستخدم في حملات تصيّد (Phishing) |
| كلمات المرور والـ Tokens | يجب تخزينها في متغيرات البيئة فقط |
| أي ملفات PDF لفواتير أو عقود | تحتوي على بيانات مالية وقانونية |

### أفضل الممارسات لحماية البيانات الحساسة
- استخدم ملف `.env` لتخزين المتغيرات الحساسة ولا ترفعه إلى GitHub (أضفه لـ `.gitignore`)
- استخدم **GitHub Secrets** أو أنظمة إدارة الأسرار (Vault, AWS Secrets Manager) للبيانات الحساسة في بيئة CI/CD
- لا تُرسل وثائق الهوية عبر تعليقات Issues أو Pull Requests
