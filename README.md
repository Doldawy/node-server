## دليل إعداد GitHub Enterprise والمنظمة (بالعربي)

> هذا الدليل يشرح الشاشات التي تظهر عند إعداد **GitHub Enterprise** و**المنظمة (Organization)** لأول مرة، مع جولة إرشادية مصوّرة للشاشات الفعلية.

---

### 1. صفحة قائمة المنظمات (`settings/organizations`)

**ما الذي تعرضه هذه الشاشة؟**

هذه الصفحة تُظهر كل المنظمات التي أنت عضو فيها أو مالكها.  
لكل منظمة ستجد:

- **اسم الرابط (slug/handle):** هو الاسم الظاهر في الرابط مباشرةً بعد `github.com/`، ويتكوّن من أحرف وأرقام وشرطات **فقط** — لا مسافات.  
  مثال: `zdoldawy-101-organization`
- **الاسم المعروض (Display name):** هو الاسم الودّي الذي يمكن أن يحتوي على مسافات.  
  مثال: `zdoldawy 101 organization`
- شارة **Owner** إذا كنت مالك المنظمة.
- زر **Settings** للوصول إلى إعدادات المنظمة.
- زر **Leave** لمغادرة المنظمة.

> **لماذا يختلف الاسم المعروض عن اسم الرابط؟**  
> GitHub يحوّل المسافات في الاسم تلقائيًا إلى شرطات (`-`) عند إنشاء الـ slug.  
> لذا تجد `zdoldawy 101 organization` كاسم معروض، بينما الرابط هو `zdoldawy-101-organization` — وكلاهما يمثّل نفس المنظمة الواحدة.

### 2. شاشة البدء السريع للمنظمة — قسم الترميز التعاوني والأتمتة

**ما الذي تعرضه هذه الشاشة؟**

بعد فتح المنظمة حديثة الإنشاء، يعرض GitHub قائمة **مهام البدء السريع (Getting Started)**، مقسّمة إلى أقسام تساعدك على إعداد المنظمة خطوة بخطوة:

- **Collaborative coding (الترميز التعاوني):**
  - *Create a pull request* — كيفية اقتراح تغييرات على المستودع.
  - *Create a branch protection rule* — تطبيق قواعد حماية على الفروع.

- **Automation and CI/CD (الأتمتة والتكامل المستمر):**
  - *Auto-assign new issues* — توزيع المشكلات تلقائيًا باستخدام GitHub Actions.
  - *Run a continuous integration test* — التحقق من الكود عبر سير عمل CI.

> هذه الشاشة طبيعية تمامًا وتظهر لكل منظمة جديدة — لا يعني ظهورها أن شيئًا ناقصًا أو أن المستودعات فارغة. هي فقط اقتراحات تعليمية.

### 3. شاشة البدء السريع للمنظمة — قسم الأمان المؤسسي

**ما الذي تعرضه هذه الشاشة؟**

الجزء الأعلى من صفحة **Getting Started** للمنظمة يعرض إعدادات الأمان ضمن Enterprise:

- **Enterprise security (أمان المؤسسة):**
  - *Enable SAML single sign-on* — تفعيل تسجيل الدخول الموحّد لإدارة هويات الأعضاء.
  - *Get automatic security updates* — التحديث التلقائي للاعتماديات الضعيفة أو القديمة.
  - *Get alerts for vulnerabilities* — تلقّي تنبيهات عن مشكلات في الكود.

- **GitHub Advanced Security:**
  - خيار لعرض إعداد الأمان المتقدم (يتطلب ترخيصًا مدفوعًا أو تجريبيًا).

> **ملاحظة عن تجربة Enterprise:**  
> إذا بدأت تجربة **GitHub Enterprise** وأنشأت المنظمة ثم توقفت، فالكيانات تبقى موجودة وعداد الأيام يستمر. هذه الشاشة ستظهر ضمن إعدادات المنظمة تحت Enterprise، وهذا سلوك طبيعي.

### 4. صفحة الملف الشخصي للمنظمة — الحالة الأولية

**ما الذي تعرضه هذه الشاشة؟**

هذه هي الصفحة الرئيسية للمنظمة (`github.com/zdoldawy-101-organization`) كما تظهر للمالك فور الإنشاء:

- **اسم المنظمة المعروض:** `zdoldawy 101 organization`
- **View as: Public** — يُتيح لك رؤية المنظمة كما يراها أي زائر عام.  
  عند التبديل لوضع Public قد تجد أن المستودعات لا تظهر — هذا طبيعي إذا لم تُضف مستودعات بعد، أو لأن المستودعات الموجودة خاصة (Private).
- رسالة **"We think you're gonna like it here"** مع قائمة مهام البدء السريع:
  - *Invite your first member* — دعوة أعضاء جدد.
  - *Customize members' permissions* — ضبط صلاحيات الأعضاء.

> **لماذا تبدو المستودعات فارغة؟**  
> المنظمة الجديدة لا تحتوي على مستودعات افتراضيًا. لإضافة مستودع:
> 1. انقر على تبويب **Repositories** في صفحة المنظمة.
> 2. اختر **New repository** لإنشاء مستودع جديد.
> 3. أو انقل مستودعًا موجودًا من حسابك الشخصي عبر **Settings → Transfer** في المستودع.

### خلاصة — الأسئلة الشائعة

| السؤال | الجواب |
|--------|--------|
| لماذا الاسم في الرابط مختلف عن الاسم المعروض؟ | GitHub يستبدل المسافات بشرطات في الـ slug. كلاهما يمثّل نفس المنظمة. |
| هل عندي منظمتان أم واحدة؟ | إذا رأيت سجلًا واحدًا في `settings/organizations` فعندك منظمة واحدة فقط. |
| لماذا المنظمة تبدو فارغة؟ | لأنك لم تُضف مستودعات بعد، أو المستودعات الموجودة خاصة. |
| ما المقصود بـ Enterprise Trial؟ | هو فترة تجريبية مدفوعة الميزات. إذا بدأتها وتركتها، تظل نشطة حتى تنتهي المدة أو تُلغيها. |
| كيف أتأكد من اسم الـ slug الصحيح؟ | افتح `github.com/settings/organizations` واضغط على المنظمة — الرابط في المتصفح هو الـ slug. |
