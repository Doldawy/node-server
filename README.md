## 📍 Plus Code & GitHub Billing Address Guide (Arabic / دليل بالعربي)

> **English summary:** This section explains what a Plus Code (Open Location Code) is, why it cannot replace a "Country" field in GitHub billing forms, and how to correctly fill in billing address details when you work remotely. It also includes a privacy note about not committing personal data to the repository.

### ما هو Plus Code وكيف تستخدمه في نماذج العناوين؟

### ما هو Plus Code؟

**Plus Code** (المعروف أيضًا بـ **Open Location Code** أو **OLC**) هو نظام ترميز جغرافي مفتوح المصدر طوّرته Google، يُحوّل أي موقع جغرافي على الأرض إلى كود نصي قصير يمكن كتابته ومشاركته بسهولة.

**مثال على شكله:**
`8G3X+Q9 الرياض` أو `MQGV+39`

يمكنك إيجاد Plus Code لأي موقع عبر:
- [Google Maps](https://maps.google.com): افتح الموقع ← اضغط على النقطة ← ستجد الكود في الأسفل.
- [plus.codes](https://plus.codes)

---

### هل يمكن كتابة Plus Code بدلًا من اسم الدولة؟

**الجواب المختصر: لا، لا يمكنه استبدال اسم الدولة في حقل "Country" المطلوب.**

| الحقل | هل يقبل Plus Code؟ | الملاحظة |
|---|---|---|
| **Country / الدولة** (قائمة منسدلة) | ❌ لا | هذا الحقل يتطلب اختيار الدولة من قائمة محددة مسبقًا — لا يُقبل فيه نص حر |
| **Address Line 1 / 2** (سطر العنوان) | ✅ ممكن | يمكنك كتابة Plus Code هنا إذا قبل الموقع نصًا حرًّا |
| **City / المدينة** | ✅ ممكن جزئيًا | بعض النماذج تقبل نصًا حرًّا |
| **Postal Code / الرمز البريدي** | ❌ لا | يُتوقع فيه رمز بريدي رسمي |

### إرشادات تعبئة نموذج الفوترة في GitHub (Organization / Enterprise)

إذا كنت تعمل عبر الإنترنت وتنتقل بين أماكن مختلفة (بدون عنوان ثابت)، اتبع الخطوات التالية عند ملء بيانات الفوترة:

1. **Country (مطلوب — قائمة منسدلة):**
   اختر **الدولة الصحيحة** التي تنتمي إليها قانونيًا أو التي تتخذها مقرًّا لعمل المنظمة (مثلًا: Saudi Arabia). هذا الحقل **إلزامي** ولا يمكن تجاوزه أو وضع Plus Code مكانه.

2. **Address Line 1:**
   يمكنك كتابة Plus Code هنا مع أي وصف إضافي، مثال:
   `8G3X+Q9 (موقع عمل متنقل)`

3. **Address Line 2 (اختياري):**
   يمكن تركه فارغًا أو إضافة ملاحظة مثل:
   `Remote / عمل عن بُعد`

4. **City:**
   اكتب اسم المدينة الأقرب أو المدينة الرئيسية في دولتك.

5. **Postal Code:**
   إذا لم يكن لديك رمز بريدي ثابت، ابحث عن الرمز البريدي للمنطقة التي تعمل بها غالبًا.

> **ملاحظة مهمة للضرائب والتحقق:** GitHub يستخدم بيانات الدولة في الفوترة لأغراض ضريبية وقانونية. تأكد دائمًا من اختيار الدولة الصحيحة لتفادي مشاكل في الفواتير أو التحقق من الهوية.
