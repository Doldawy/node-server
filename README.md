## عدد المنظمات (Organizations) — شرح بالعربي

### كيف تعدّ منظماتك على GitHub؟

افتح الرابط:  
**https://github.com/settings/organizations**

ستظهر لك قائمة بكل المنظمات التي أنت عضو فيها أو مالك لها.  
**عدد المنظمات = عدد العناصر (البطاقات) الظاهرة في تلك القائمة.**

### الفرق بين الاسم المعروض (Display name) واسم الرابط (Slug)

| النوع | مثال | الاستخدام |
|---|---|---|
| **Display name** (الاسم المعروض) | `zdoldawy 101 organization` | يظهر في واجهة GitHub للقراءة |
| **Slug / Handle** (اسم الرابط) | `zdoldawy-101-organization` | يُستخدم في الرابط: `github.com/<slug>` |

- GitHub يحوّل **المسافات** في الاسم المعروض إلى **شرطات** (`-`) تلقائيًا عند إنشاء الرابط.  
- لهذا السبب قد يبدو أن لديك "اسمين"، لكنهما في الحقيقة **نفس المنظمة الواحدة**.
- للوصول إلى المنظمة عبر الرابط استخدم الـSlug دائمًا:  
  `https://github.com/zdoldawy-101-organization`
